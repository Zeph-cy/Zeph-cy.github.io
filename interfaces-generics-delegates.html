接口，泛型与委托

Interfaces, Generics & Delegates

1. 接口 (Interfaces)

接口是面向对象编程中的一个重要概念，它定义了一组方法、属性或事件的契约，但不提供实现。 接口允许不同的类实现相同的行为规范，从而实现多态性。

接口的特点：

  • 定义行为契约，不包含实现
  • 支持多重继承（一个类可以实现多个接口）
  • 提高代码的可扩展性和可维护性
  • 实现松耦合设计

C# 接口示例：

// 定义接口
public interface IAnimal
{
    void MakeSound();
    void Move();
}

// 实现接口
public class Dog : IAnimal
{
    public void MakeSound()
    {
        Console.WriteLine("Woof!");
    }

    public void Move()
    {
        Console.WriteLine("Dog runs");
    }
}

2. 泛型 (Generics)

泛型允许您编写类型安全的代码，同时提高代码重用性。通过使用泛型，可以创建类、方法、接口和委托， 这些类型参数可以在使用时指定具体类型，从而避免类型转换和装箱/拆箱操作。

泛型的优势：

  • 类型安全：编译时类型检查
  • 性能优化：避免装箱和拆箱
  • 代码重用：一次编写，多种类型使用
  • 更清晰的代码：减少类型转换

C# 泛型示例：

// 泛型类
public class Stack<T>
{
    private List<T> items = new List<T>();

    public void Push(T item)
    {
        items.Add(item);
    }

    public T Pop()
    {
        if (items.Count == 0) throw new InvalidOperationException();
        T item = items[items.Count - 1];
        items.RemoveAt(items.Count - 1);
        return item;
    }
}

// 使用
Stack<int> intStack = new Stack<int>();
Stack<string> stringStack = new Stack<string>();

3. 委托 (Delegates)

委托是一种引用类型，用于封装方法。委托类似于C/C++中的函数指针，但更加类型安全。 委托常用于实现事件和回调方法，是实现观察者模式的基础。

委托的特点：

  • 类型安全的函数指针
  • 支持多播（一个委托可以调用多个方法）
  • 是事件的基础
  • 支持匿名方法和Lambda表达式

C# 委托示例：

// 定义委托
public delegate void MathOperation(int a, int b);

public class Calculator
{
    public static void Add(int a, int b)
    {
        Console.WriteLine($"Sum: {a + b}");
    }

    public static void Multiply(int a, int b)
    {
        Console.WriteLine($"Product: {a * b}");
    }
}

// 使用委托
MathOperation operation = Calculator.Add;
operation(5, 3); // 输出: Sum: 8

// 使用Lambda表达式
MathOperation lambdaOp = (a, b) => Console.WriteLine($"Result: {a - b}");
lambdaOp(10, 4); // 输出: Result: 6

三者的关系

接口、泛型和委托是现代编程语言中的重要特性，它们经常一起使用：

  • 接口 + 泛型: 可以创建泛型接口，如 IEnumerable<T>，提供类型安全的集合操作
  • 接口 + 委托: 接口可以定义委托类型的成员，用于回调机制
  • 泛型 + 委托: .NET提供了泛型委托如 Action<T> 和 Func<T, TResult>
  • 三者结合: 在LINQ等高级特性中，三者协同工作实现强大的功能

综合示例：

// 泛型接口
public interface IRepository<T>
{
    void Add(T item);
    T Get(int id);
    void ProcessAll(Action<T> processor); // 使用泛型委托
}

// 实现
public class UserRepository : IRepository<User>
{
    private List<User> users = new List<User>();

    public void Add(User item) => users.Add(item);
    public User Get(int id) => users.FirstOrDefault(u => u.Id == id);
    public void ProcessAll(Action<User> processor)
    {
        foreach (var user in users)
            processor(user);
    }
}
